# 404 Turret Game - Браузерное расширение

Браузерное расширение, которое заменяет **только настоящие** страницы ошибки 404 на захватывающую мини-игру с турелью!

## 🎮 Описание игры

- **Турель** в центре экрана следует за курсором мыши
- **Враги (вирусы)** появляются с краев экрана и движутся к центру
- **3 клика** по врагу для его уничтожения
- **Счетчик очков** в правом верхнем углу
- **Увеличивающаяся сложность** со временем

## 🛡️ Умное обнаружение 404

Расширение использует многоуровневую систему проверки, чтобы активироваться **только на настоящих страницах 404**:

- ✅ **HTTP статус проверка** - определяет реальные 404 ошибки
- ✅ **Анализ заголовков** - ищет ключевые фразы в title и h1-h2
- ✅ **Проверка контента** - анализирует текст на наличие ошибок 404
- ✅ **Исключение популярных сайтов** - не запускается на Google, YouTube, GitHub и др.
- ✅ **Фильтрация путей** - исключает /login, /admin, /api и другие служебные страницы
- ✅ **Проверка размера контента** - 404 страницы обычно короткие
- ✅ **Множественные условия** - требует выполнения минимум 2 условий

## 🚀 Установка

### Для Chrome/Edge:

1. Скачайте или клонируйте этот репозиторий
2. Откройте Chrome и перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode)
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку с расширением `404-game`

### Для Firefox:

1. Скачайте или клонируйте этот репозиторий
2. Откройте Firefox и перейдите в `about:debugging`
3. Нажмите "Этот Firefox" (This Firefox)
4. Нажмите "Загрузить временное дополнение" (Load Temporary Add-on)
5. Выберите файл `manifest.json` в папке расширения

## 🎯 Как играть

1. Когда расширение установлено, перейдите на любую страницу 404
2. Страница автоматически заменится на игровой экран
3. Наведите мышь на турель - она будет следовать за курсором
4. Кликайте по врагам (синие круги) чтобы их уничтожить
5. Каждый враг требует 3 клика для полного уничтожения
6. Зарабатывайте очки и побивайте свои рекорды!

## 🔧 Технические детали

- **Manifest Version**: 3 (современный стандарт)
- **Permissions**: `activeTab` (минимальные права доступа)
- **Умное обнаружение**: Многоуровневая система проверки 404 страниц
- **Fallback логика**: Встроенные стили и логика если файлы не загрузились
- **Адаптивный дизайн**: Работает на десктопе и мобильных устройствах
- **Безопасность**: Исключение популярных сайтов и ложных срабатываний

## 🚫 Исключения (расширение НЕ активируется на):

- Популярных сайтах: Google, YouTube, Facebook, GitHub, VK, Yandex и др.
- Служебных страницах: /login, /admin, /api, /search, /profile
- Локальных файлах и специальных протоколах
- Страницах с большим количеством контента или ссылок
- Страницах с активными формами ввода

## 🎨 Особенности

- Красивые градиентные эффекты
- Анимации появления и уничтожения врагов
- Эффекты частиц при попаданиях
- Плавные переходы и hover-эффекты
- Адаптивная сложность (игра становится сложнее со временем)
